# Changelog

## 1.0.0

Initial standalone version, extracted from Arcadeia.

- Select A and B directly on the existing Video.js progress bar.
- Mouse, touch and keyboard controls with range markers and status instructions.
- Separate full-video repeat toggle.
- Hover thumbnail compatibility during selection.
- Public `setRange` and `getRange` API, automatic source reset and disposal cleanup.
- ES module, CommonJS and browser bundles; packaged CSS and SVG icons.
- Demo, component tests and GitHub Actions checks.
